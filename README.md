# ORBIT ROOM

Your room has gravity.

A mixed reality game played with your hands at your desk. The things in your room become a
solar system. Pinch the pouch, pull back, let go, and put a rocket into orbit.

**Play** Open https://rapha18th.github.io/orbitroom/ in your headset's browser, sitting at a desk.

**Device check** https://rapha18th.github.io/orbitroom/canary.html runs a two-minute check of pinch, poke, room labels and frame rate.

**Testers** https://rapha18th.github.io/orbitroom/?tester=1 sends frame times, hand and head positions, the headset and browser version, the room's
object labels and launch results to the ORBIT ROOM team. Each report is labelled with a random session code and is deleted
after 30 days. The device check sends the same kind of report.

Built with the Immersive Web SDK. This repository holds the built game only.
